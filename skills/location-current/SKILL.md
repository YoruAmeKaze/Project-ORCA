# 本机定位能力

## 使用边界

- 只读，调用 Action：`location.current`。
- 参数必须是空 JSON 对象 `{}`。
- 仅在用户请求“我的位置”“当前位置”“附近”“最近”或按距离查询时调用。
- 定位权限关闭、系统服务无数据或超时都必须把运行时错误如实反馈给用户，不猜测城市或坐标。
- 坐标仅供瑞幸附近门店查询使用，保存在进程内短期缓存，不进入 Dashboard、Memory、InfoStore 或日志。

## 运行配置

通过本机私密配置显式启用：`ORCA_LOCATION_ENABLED=1`。Windows 隐私设置必须允许桌面应用访问定位。
